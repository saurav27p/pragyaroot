# PragyaRoot components

The homepage is intentionally self-contained in `index.html` so it works on GitHub Pages and static hosting without server-side includes. Shared assets are organized as:

- `css/style.css` — all site styles and responsive layout
- `js/script.js` — theme, drawer, search, animation, back-to-top, and contact form behavior
- `components/` — reserved for future reusable HTML fragments
